# Nourish - прототип v0.1

Мобильный интерфейс PWA на React + TypeScript + Vite.

## Запуск
1. Установить Node.js LTS.
2. В папке проекта выполнить `npm install`.
3. Выполнить `npm run dev`.
4. Для проверки production-сборки: `npm run build`.

## Важно
Это первый локальный прототип интерфейса, а не готовая система учёта.
Пока нет серверной базы, авторизации, распознавания фото, штрихкодов,
точных расчётов КБЖУ, полноценного склада и синхронизации между устройствами.
Граммовки, отсутствующие в исходном меню, намеренно не придуманы.
Перед использованием меню нужно сверить с исходными скриншотами.

## Изменения v0.2
- Покупки и домашние остатки объединены в один раздел «Покупки».
- В карточке продукта предусмотрены три показателя: нужно по меню, есть дома, осталось купить.
- «Питание» переименовано в «Дневник питания»: фактически съеденная еда и КБЖУ за день.
